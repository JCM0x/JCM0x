# OSINT

Espacio para futuras investigaciones basadas exclusivamente en fuentes públicas y dentro de un alcance legítimo.

Cada caso deberá documentar:
- objetivo y alcance
- fuentes públicas utilizadas
- metodología
- validación y limitaciones
- conclusiones
- protección de datos personales

No publicar PII innecesaria ni investigar personas privadas fuera de un propósito legítimo.
