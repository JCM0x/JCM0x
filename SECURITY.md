# Security Policy

## Responsible Use

This repository is intended for education, research, and authorized security testing.

Do not use the material here against systems you do not own or do not have explicit permission to test.

## Secrets

Never submit:

- Passwords
- API keys
- Access tokens
- Private keys
- Session cookies
- Database credentials
- Personal or confidential data

Use environment variables, secret managers, and sanitized examples instead.

## Vulnerabilities in This Repository

For vulnerabilities affecting code in this repository, please report them privately rather than publishing exploit details in a public issue.
